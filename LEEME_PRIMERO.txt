MITIENDA - FULL STACK

1. Extrae el ZIP completo. No ejecutes archivos desde dentro del ZIP.
2. Instala Node.js 24 o superior desde https://nodejs.org/
3. En Windows abre INICIAR_TIENDA.cmd. Se preparan las dependencias y Java 21
   portatil si hace falta. La primera vez necesitas Internet y paciencia.
4. Abre http://127.0.0.1:5173/ y manten la ventana de inicio abierta.

En Visual Studio Code: npm ci y luego npm run dev:full.
En macOS o Linux instala tambien JDK 21 y ejecuta sh iniciar.sh.
Maven se descarga automaticamente mediante el wrapper incluido.
